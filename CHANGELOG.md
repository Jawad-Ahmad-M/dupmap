# Changelog

## 0.1.0

- Recursive terminal treemap with bordered boxes and navigation
- Navigable list view and filename filtering
- Size, name, and modified-time sorting
- Depth, file-type, and size-heat color modes
- Duplicate report with hash plus byte verification
- Duplicate highlighting and reclaimable-space estimates
- Percentage labels, recursive file counts, and a color legend
- Symlink skipping, permission handling, empty-directory handling, and
  navigable `other` groups for tiny files
- Make/CMake builds, install targets, man page, tests, CI, and Linux release
  packaging
